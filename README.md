# NovaCommerce

NovaCommerce es un proyecto ficticio de una plataforma de e-commerce diseñada para simular una infraestructura empresarial en AWS utilizando Infrastructure as Code con Terraform.

El objetivo del repositorio es documentar, diseñar y luego implementar una arquitectura escalable, segura y reproducible, similar a la que podría usar una empresa real.

## Objetivo del proyecto

Construir una base técnica profesional que incluya:

- documentación clara del negocio y la arquitectura,
- buenas prácticas de infraestructura,
- estructura modular,
- despliegue automatizado con Terraform,
- y una presentación atractiva para portafolio y LinkedIn.

## Estado actual

- Documentación inicial en progreso
- Arquitectura en definición
- Terraform aún no implementado

## Temática

NovaCommerce representa una empresa de tecnología y comercio electrónico que vende productos como notebooks, smartphones, accesorios y periféricos en Latinoamérica.
