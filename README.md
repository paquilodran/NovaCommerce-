# Introducción

NovaCommerce es una empresa ficticia dedicada al comercio electrónico de productos tecnológicos en Latinoamérica.

Durante los últimos años la compañía ha experimentado un crecimiento acelerado, aumentando considerablemente el número de clientes, pedidos y servicios digitales.

Como consecuencia, la infraestructura existente comenzó a presentar limitaciones importantes relacionadas con la escalabilidad, la disponibilidad y la administración manual de recursos.

Con el objetivo de modernizar la plataforma tecnológica, la empresa decidió adoptar una estrategia basada en **Infrastructure as Code (IaC)** utilizando **Terraform** sobre **Amazon Web Services (AWS)**.

Este repositorio documenta todo el proceso de diseño, planificación e implementación de dicha infraestructura.

---

# Objetivos

El proyecto busca construir una plataforma cloud que sea:

- Escalable
- Segura
- Reproducible
- Modular
- Automatizable
- Fácil de mantener

siguiendo prácticas utilizadas en equipos de Cloud Engineering y DevOps.

---

# Objetivos técnicos

- Automatizar completamente la infraestructura.
- Eliminar configuraciones manuales.
- Utilizar Terraform como única fuente de verdad.
- Implementar arquitectura modular.
- Separar ambientes Dev, Staging y Production.
- Documentar todas las decisiones técnicas.
